# پنل مدیریت VLESS (WS + XHTTP) روی Railway

یک سرویس تک‌فایلی مبتنی بر **Xray-core** که پروتکل‌های **WebSocket** و **XHTTP** را روی یک پورت واحد (سازگار با Railway) اجرا می‌کند و یک **پنل وب لوکس با صفحه ورود** برای ساخت/حذف کاربر و مشاهده وضعیت سیستم دارد.

---

## ✨ امکانات

- پروتکل VLESS روی **WS** و **XHTTP** (mode: `packet-up`) پشت TLS رایگان Railway
- صفحه **ورود** با نام کاربری/رمز عبور (قابل تغییر از داخل پنل)
- داشبورد با **منوی همبرگری**: داشبورد، اینباندها، کلاینت‌ها، تنظیمات
- **مانیتور زنده** مصرف CPU، RAM، دیسک و مدت زمان آپ‌تایم
- ساخت/حذف نامحدود کاربر، هرکدام با لینک آماده کپی برای WS و XHTTP
- طراحی شیشه‌ای (glassmorphism) با فونت **وزیرمتن**
- ذخیره‌سازی روی Volume اختیاری (`/data`) تا اطلاعات با هر دیپلوی پاک نشود

---

## 🚀 راه‌اندازی روی Railway

### ۱. ساخت ریپو
تمام فایل‌های این پروژه (`Dockerfile`, `panel.py`, `README.md`, `index.html`) را در یک ریپوی GitHub قرار دهید.

### ۲. ساخت پروژه در Railway
`New Project → Deploy from GitHub repo` و ریپوی خود را انتخاب کنید. Railway به‌صورت خودکار `Dockerfile` را تشخیص می‌دهد.

### ۳. تنظیم متغیرها (Variables)

| نام | مقدار | توضیح |
|---|---|---|
| `PORT` | `8080` | پورت داخلی سرویس |
| `UUID` | یک UUID ثابت | کاربر پیش‌فرض؛ از [uuidgenerator.net](https://www.uuidgenerator.net/) بسازید |
| `ADMIN_USER` | دلخواه (پیش‌فرض `admin`) | نام کاربری ورود به پنل |
| `ADMIN_PASSWORD` | دلخواه | رمز ورود به پنل (اگر خالی بماند، همان `UUID` است) |

> بعداً می‌توانید نام کاربری و رمز را از داخل خود پنل (بخش «تنظیمات») هم تغییر دهید.

### ۴. فعال‌سازی دامنه
`Settings → Networking → Generate Domain` و Target Port را `8080` بگذارید.

### ۵. (اختیاری ولی پیشنهادی) افزودن Volume برای ذخیره‌سازی دائمی
`Settings → Volumes → New Volume`، مسیر Mount را `/data` بگذارید تا کاربرانی که در پنل می‌سازید با هر دیپلوی جدید پاک نشوند.

### ۶. ورود به پنل
آدرس `https://<دامنه شما>/panel` را باز کنید و با نام کاربری/رمزی که تنظیم کردید وارد شوید.

## 🧩 استفاده از پنل

- **داشبورد**: وضعیت لحظه‌ای CPU، RAM، دیسک و تعداد کاربران فعال.
- **اینباندها**: مشخصات فنی Path و Mode مربوط به WS و XHTTP.
- **کلاینت‌ها**: ساخت کاربر جدید با یک نام دلخواه؛ هر کاربر دو لینک `vless://` (یکی WS و یکی XHTTP) می‌گیرد که با دکمه کپی می‌شود.
- **تنظیمات**: تغییر نام کاربری و رمز ورود به پنل.

لینک‌های ساخته‌شده را در اپلیکیشن‌هایی مثل **v2rayNG**، **Hiddify**، **Streisand** یا **V2Box** با گزینه Import from Clipboard وارد کنید.

---

## ⚠️ نکات مهم

- Railway فقط ترافیک HTTP/HTTPS را عبور می‌دهد، بنابراین پروتکل‌هایی مثل Reality/TCP خام/gRPC مستقیم کار نمی‌کنند؛ فقط **WS** و **XHTTP** پشتیبانی می‌شوند.
- هر بار ساخت یا حذف کاربر باعث چند ثانیه ری‌استارت Xray می‌شود.
- پلن رایگان Railway محدودیت مصرف ماهانه دارد؛ برای استفاده مداوم پلن پولی را در نظر بگیرید.
- اگر دامنه پیش‌فرض Railway در ایران فیلتر شد، از یک دامنه اختصاصی پشت Cloudflare استفاده کنید.
